# Third-party dependencies

Python 의존성은 `requirements.txt`, `requirements-docker.txt`, `requirements-docker.lock`으로 지정합니다. 패키지별 저작권과 라이선스는 각 배포물에 포함된 고지를 따릅니다. 이 저장소는 해당 패키지 소스를 번들링하지 않습니다.

데이터가 내장된 대시보드와 vendored Leaflet/MarkerCluster 자산은 이 공개본에 포함하지 않습니다. 따라서 개발 저장소 전용 자산 고지나 존재하지 않는 `preview/` 파일 링크를 복사하지 않았습니다.

보행망·지오코딩 데이터 출처는 [데이터 출처](data-attribution.md)를 참고하세요. 외부 데이터와 라이브러리의 조건은 프로젝트 코드 전체에 대한 사용 허가를 뜻하지 않습니다. 프로젝트 코드 라이선스는 [LICENSE_PENDING](../PUBLICATION_MANIFEST.md#license_pending) 상태입니다.
