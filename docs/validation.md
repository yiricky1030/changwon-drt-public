# Validation and unresolved questions

이 문서는 분석 진단의 목적과 해석 한계를 요약합니다. 공급과 이용의 인과 방향, 목적지 접근성, 외부 benchmark 및 현장 검증까지 해결되었다는 뜻은 아닙니다.

| 검증 | 핵심 경계 |
|---|---|
| Coverage·관측 메커니즘 | 관측된 정류소가 전체를 대표한다고 가정하지 않음 |
| LOO·가중치·기여도 | 안정성, 지표 의존성, 정책 타당성을 구분 |
| Moran·공간 모형 | 인접성 정의에 민감; 공간적 연관은 인과가 아님 |
| 인구격자·MAUP | 마스킹·결측·격자별 기준시점 혼재; 주민 개별 origin을 관측한 것이 아님 |
| 경계 진단 | 인접 동 공급을 함께 확인하되 도로망 거리와 실제 보행 가능성은 구분 |
| Missingness | 가정별 민감성을 표시하며 관측되지 않은 참값을 복원했다고 주장하지 않음 |
| Field/user validation | 프로토콜·평가 방법과 실제 조사 완료를 구분; 현장·사용자 검증 미완료 |

공개본에서 실행한 검사 결과는 [public-qa.md](public-qa.md)에 기록합니다. 데이터 의존 통합·브라우저·실서비스 API·DB 검증은 이번 공개본 QA에서 수행하지 않았습니다.
